## What Naaz Tells Forward to Trainers (Trainer Onboarding Talk)

- **Read the Trainer Handbook first** -- covers philosophy, rules, session structure, everything
- **Check the Course-Project Map** -- find your course, see which projects are READY vs which you need to build
- **Follow the 5 rules:**
  1. No concept without project context
  2. Every session ends with a deliverable
  3. Portfolio checkpoint every 2 weeks
  4. Final session is presentation, not exam
  5. AI is phased (Foundation: no AI, Building: AI assists, Amplification: AI co-creates)
- **Follow the 70-20-10 structure** -- 20% teach, 70% students build, 10% portfolio save
- **Use starter templates where available** -- don't recreate from scratch
- **Every student must have a portfolio by course end** -- tech students on GitHub Pages, non-tech on Notion/Carrd
- **When you build a new project for a dev course** -- follow the README quality of existing projects (show them `01_quiz_master/README.md` as the gold standard), then update the Course-Project Map
