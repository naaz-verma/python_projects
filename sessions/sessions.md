# WorldWithWeb -- Sessions & Programs

All sessions operate on **3 Levels** across **2 audience segments**.

| Level | Purpose | Format |
|-------|---------|--------|
| **Level 1** | Inspiration & Awareness | Free talks (1-1.5 hrs) |
| **Level 2** | Skill Building | Paid bootcamps / recurring sessions |
| **Level 3** | Career & Personal Development | Add-on program (6 sessions) |

| Segment | Audience | Focus |
|---------|----------|-------|
| **School** | Classes 8-10 | Python, AI, cybersecurity, game dev -- build from fundamentals |
| **College & Professional** | College students, early professionals | Market-ready skills -- automation, web, marketing, AI tools |

### Biweekly Special Sessions (Recurring, Every Batch)

Self-contained -- students can miss one without falling behind. Repeat for every new batch.

#### Category 1: Tech Awareness (Discussion + Demo, No Coding)

| # | Session | Hook | What They Learn |
|---|---------|------|-----------------|
| S1 | **How the Internet Actually Works** | "What happens in 0.3 seconds between typing google.com and seeing the page?" | DNS, HTTP, servers, IP, packets |
| S2 | **AI: What It Actually Is (and Isn't)** | "ChatGPT doesn't think. Let me show you what it actually does." | Tokens, probabilities, training data, hallucinations |
| S3 | **How Apps Make Money** | "Instagram is free. So how is it worth $100 billion?" | SaaS, freemium, ads, data models |
| S4 | **Tech Careers Nobody Tells You About** | "50+ job roles in tech. You've heard of 3." | DevOps, product, UX, security, data engineering |
| S5 | **Open Source & How Software Is Really Built** | "The code behind your browser, your OS, even AI -- it's all public." | GitHub, open source culture |

#### Category 2: Hands-On Skill Sessions (Workshop, Build Something)

| # | Session | Hook | What They Build |
|---|---------|------|-----------------|
| S6 | **Linux & The Terminal** | "Every hacker, server, and Android phone runs Linux." | Basic commands, file navigation, WSL setup |
| S7 | **Git & GitHub: Your Code Portfolio** | "How every developer in the world saves and shares code." | GitHub account, push first project |
| S8 | **HTML + CSS: Build Your Website** | "Build your personal website. Today. For free." | Single-page portfolio site on GitHub Pages |
| S9 | **Web Scraping with Python** | "Pull any data from any website automatically." | Scrape live data with Python |
| S10 | **Build a Telegram/Discord Bot** | "A bot that runs in your actual group chat." | Working bot that responds to commands |
| S11 | **Prompt Engineering Workshop** | "Same AI, wildly different results. The difference is how you ask." | Hands-on prompt crafting, comparing outputs |
| S12 | **APIs: Connecting Everything** | "Weather apps, payment gateways, AI -- it's all APIs." | Call 3 public APIs, display results |

#### Category 3: Challenge Sessions (Competitive, High Energy)

| # | Session | Hook | Format |
|---|---------|------|--------|
| S13 | **CTF Day (Capture The Flag)** | "Real cybersecurity challenges. Crack codes, find hidden flags." | Beginner CTF, teams compete |
| S14 | **Debug Battle** | "I wrote broken code on purpose. First team to fix all bugs wins." | Timed debugging challenges |
| S15 | **AI vs Human Quiz-Off** | "Can you write a better answer than ChatGPT?" | Students vs AI, class votes |
| S16 | **Mini Hackathon** | "2 hours. Build something. Anything. Best project wins." | Teams of 2-3, build and present |

#### Suggested Rotation (pick 12 per batch, biweekly = ~6 months)

| Session | Topic | Type |
|---------|-------|------|
| 1 | How the Internet Actually Works | Awareness |
| 2 | Linux & The Terminal | Hands-On |
| 3 | Git & GitHub | Hands-On |
| 4 | AI: What It Actually Is | Awareness |
| 5 | CTF Day | Challenge |
| 6 | Web Scraping | Hands-On |
| 7 | Prompt Engineering | Hands-On |
| 8 | How Apps Make Money | Awareness |
| 9 | Build a Telegram/Discord Bot | Hands-On |
| 10 | HTML + CSS: Build Your Website | Hands-On |
| 11 | Tech Careers Nobody Tells You About | Awareness |
| 12 | Mini Hackathon | Challenge |

> **Note:** Sessions 2A, 2B, and 2C are one-time sessions for the current batch. The biweekly rotation above resumes after these are completed. Session S7 (Git & GitHub) can be skipped for students who attended Session 2C.

# COLLEGE & PROFESSIONAL SEGMENT

---

## Level 1: Inspiration Talks

**Duration:** 1-1.5 hours | **Audience:** Entire college / mixed batches | **Goal:** Mindset shift + funnel into Level 2

### Talk Option A: Digital Marketing & AI -- Building Your Online Presence
- Visibility > silence -- why every student needs a digital presence
- Digital marketing + AI for every student (tech and non-tech)
- Mini hands-on: Build a real online presence in the session

### Talk Option B: Tech + Portfolio = Future-Proof Career
- Why skills alone aren't enough anymore
- Portfolio > marks (with real examples)
- GitHub, LinkedIn, personal websites -- what recruiters actually look for

### Talk Option C: AI Demystified -- From Hype to Real Skills
- What AI actually is (and isn't) -- cut through the noise
- Live demo: Build an AI app in 15 minutes
- Jobs AI creates vs jobs AI replaces
