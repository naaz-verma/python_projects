# Project 9: AI Dungeon Escape

A puzzle-based escape room game powered by AI. Navigate through mysterious dungeon rooms, solve AI-generated puzzles, collect keys, and escape before you run out of hints!

---

## Prerequisites

- A laptop/PC with Windows 10 or 11
- Basic Python knowledge (variables, functions, lists, dictionaries, loops, if/else, strings)
- Completed the Python Starter course

---

## What Is This Project About?

You are trapped in a dungeon. Each room has a locked door guarded by a puzzle. The puzzles are **generated by AI** (Google's Gemini model), so every playthrough is different. Solve the puzzle to earn a key and move to the next room. Use hints if you get stuck -- but hints cost you points!

**Features:**
- 3 difficulty levels (Easy: 3 rooms, Medium: 4 rooms, Hard: 5 rooms)
- AI-generated riddles and puzzles unique to each room's theme
- Up to 3 progressive hints per room
- Inventory system that tracks your collected keys
- Scoring system with grades (S/A/B/C/D) and hint penalties

## Step-by-Step Setup

### Step 0: Check if Python is Installed

Open **Command Prompt** (search "cmd" in Start menu) and type:

```bash
python --version
```

You should see something like `Python 3.12.x`. If you get an error:
1. Download Python from [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. **IMPORTANT: Check the box "Add Python to PATH"** during installation
3. Restart your command prompt after installing

Also verify pip:

```bash
pip --version
```

If `pip` gives an error, try `python -m pip --version` instead.

### Step 1: Install VS Code (if not installed)

1. Download from [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. Install with default settings
3. Open VS Code
4. Install the **Python extension**: click Extensions icon (left sidebar) > search "Python" > install the one by Microsoft

### Step 2: Open the Project Folder

1. In VS Code: **File > Open Folder** > navigate to `09_ai_dungeon_escape` folder
2. Open the terminal: **Terminal > New Terminal** (or press `` Ctrl + ` ``)
3. Make sure the terminal shows you're inside the project folder

### Step 3: Install Required Packages

Run these commands **one by one** in the VS Code terminal:

```bash
pip install streamlit
pip install python-dotenv
pip install requests
```

If `pip` doesn't work, try with `python -m pip` instead:
```bash
python -m pip install streamlit
python -m pip install python-dotenv
python -m pip install requests
```

**What each package does:**
| Package | Why We Need It |
|---------|---------------|
| `streamlit` | Turns our Python code into a web app (no HTML/CSS needed) |
| `python-dotenv` | Reads our secret API key from a `.env` file safely |
| `requests` | Sends HTTP requests to the Gemini API |

### Step 4: Get Your Gemini API Key (Free)

1. Go to [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Sign in with your Google account
3. Click **"Create API Key"**
4. Copy the key

### Step 5: Create Your `.env` File

1. In the project folder, create a new file called `.env` (just `.env`, no name before the dot)
2. Add this line (replace with your actual key):

```
GEMINI_API_KEY=paste_your_key_here
```

3. Save the file

**Important:** Never share your `.env` file or upload it to GitHub. It contains your secret key.

### Step 6: Run the App

From the terminal, make sure you're inside the `09_ai_dungeon_escape` folder, then run:

```bash
streamlit run app.py
```

If that doesn't work, try:
```bash
python -m streamlit run app.py
```

This will automatically open your browser at `http://localhost:8501` with the game running.

To **stop the app**: press `Ctrl+C` in the terminal.

## Project Files -- What Each File Does

Read the files in this order when learning:

### File 1: `utils.py` -- The AI Connector (Read This First)

**What it does:** Connects your Python code to Google's Gemini AI using their REST API.

**Key concepts:**
- `requests.post()` -- sends data to Google's AI server and gets a response back
- `os.getenv()` -- reads the API key from your `.env` file
- `dotenv.load_dotenv()` -- loads the `.env` file into your program

**Three classes:**
```
GeminiModel      --> Sends prompts to the AI and gets responses
GeminiChat       --> Manages a back-and-forth conversation with the AI
GeminiResponse   --> Wraps the AI's response so we can easily get the text
```

### File 2: `game_engine.py` -- The Game Logic (Read This Second)

**What it does:** Contains all the game rules -- rooms, puzzles, scoring, and answer checking.

**Key concepts:**
- Dictionaries for room data (`ROOMS` with easy/medium/hard categories)
- AI prompt engineering (telling the AI exactly what JSON format to return)
- `json.loads()` -- parsing JSON text from the AI into Python dictionaries
- `re.sub()` -- cleaning up markdown formatting from AI responses
- Score calculation with difficulty multipliers and hint penalties

**Key functions:**
```
get_rooms_for_difficulty()  --> Returns the room list for easy/medium/hard
generate_puzzle()           --> Asks AI to create a puzzle for a specific room
check_answer()              --> Compares player's answer with the correct answer (fuzzy matching)
get_score()                 --> Calculates final score with grade (S/A/B/C/D)
```

### File 3: `app.py` -- The Interface (Read This Last)

**What it does:** The Streamlit web interface that connects everything together.

**Key concepts:**
- `st.session_state` -- remembers game state between button clicks (current room, inventory, score)
- `st.progress()` -- shows how many rooms you've solved
- `st.text_input()` -- where the player types their answer
- `st.button()` -- Submit, Hint, Next Room, Play Again buttons
- `st.rerun()` -- refreshes the page when state changes

**Three screens:**
1. **Welcome Screen** -- instructions, difficulty descriptions, how to play
2. **Gameplay Screen** -- puzzle display, answer input, hints, room progress
3. **Victory Screen** -- final score, grade, room-by-room breakdown

## How It Works (Simple Explanation)

```
Player clicks "Start Game" with chosen difficulty
        |
game_engine.py picks rooms for that difficulty
        |
For each room:
   - generate_puzzle() asks AI to create a themed puzzle
   - Player sees the puzzle and types an answer
   - check_answer() compares player's answer to correct answer
   - If wrong: player can try again or use hints (up to 3)
   - If correct: key added to inventory, move to next room
        |
After all rooms:
   - get_score() calculates final score
   - Score depends on: rooms solved, hints used, difficulty
   - Player sees grade (S = perfect, D = used lots of hints)
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `ModuleNotFoundError: No module named 'streamlit'` | Run `pip install streamlit` |
